# Локальная панель магазинов на Mac

Одна панель для аккаунтов, локальных проверок Instagram, персональных демо,
первых сообщений, заметок и работы с клиентом. Apify не используется.

## Открыть

Дважды нажмите `scripts/Магазины.command` или выполните:

```sh
cd /путь/instagram-store-finder
.venv/bin/python -m store_finder desk
```

Панель: http://127.0.0.1:8765. Это локальное приложение в браузере.
Если уже запущено, повторный запуск ярлыка просто открывает панель.
Окно Терминала с приложением нужно оставить открытым. Ctrl+C завершает работу.

Для новой установки достаточно Python 3.9+ и локальных зависимостей:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-local.txt
```

## Ежедневная работа

1. Оставьте Chrome открытым с входом в Instagram и Google. Включите
   `Allow remote debugging` в `chrome://inspect/#remote-debugging`.
2. В панели нажмите «Получить из таблицы». Новые аккаунты из листа «Магазины»
   добавятся в локальную очередь. Таблица остаётся закрытой; Chrome использует
   ваш обычный доступ Google. Cookies и ключи Google не экспортируются.
3. Откройте «Настройки», введите ключ Delokay и включите публикацию демо,
   если нужны готовые публичные ссылки. Ключ остаётся в памяти процесса;
   после перезапуска приложения его нужно ввести снова.
4. Нажмите «Обработать очередь» или включите «Автоочередь». По умолчанию
   обрабатываются три аккаунта за проход. Автоочередь продолжает следующую
   партию каждые 30 секунд после завершения предыдущей и периодически
   загружает новые строки таблицы (по умолчанию раз в час).
5. В карточке аккаунта проверяйте информацию, фото и подписи, открывайте демо,
   копируйте сообщение, меняйте статус работы и сохраняйте заметку.

Ежедневный поиск GitHub → Google Sheets продолжает находить аккаунты независимо
от Mac. Локальное приложение обрабатывает строки, пока Mac и Chrome доступны.
Спящий или выключенный Mac ничего не обрабатывает; очередь остаётся в базе.
Все операции последовательны. Остановка завершается после текущего аккаунта.
При ограничении Instagram или ошибке подключения автоочередь отключается.

## Что проверяется

- Профиль, название, био, ссылки, логотип, подписчики и даты публикаций.
- До шести полученных фотопубликаций и до восьми фото каждой карусели.
- Исходные подписи сохраняются без перевода, Reels и видео исключаются.
- Ссылки сайта проверяются существующим модулем, результат отбора виден в карточке.
  Проверка сайта не равна доказательству, что это интернет-магазин.
- Язык демо выбирается по био и подписям: русский, английский, испанский,
  португальский, французский, итальянский, турецкий, польский, японский или немецкий.
  Для остальных языков используется английский; исходные подписи сохраняются. Валюта и шаблон
  задаются в настройках; сведения о ценах и наличии не выдумываются.
- После создания демо проверяются товары и доступность фото, затем создаётся
  первое сообщение с публичной ссылкой. Сообщение автоматически не отправляется.

Очередь не ограничена статусом «Подходит» из старой проверки Apify. Импортируются
все строки, а локальный проход читает текущий Instagram. Уже контактированные,
купившие и вручную исключённые аккаунты автоматически не обрабатываются;
их можно открыть и проверить отдельно. Профили без достаточного материала
остаются в «Нужна проверка», сетевые ошибки требуют явного повторного запуска.

Повторный сбор сохраняет прежние локальные файлы и создаёт новый пакет.
Опубликованные демо повторно не собираются: для них доступно обновление языка
и контактов с сохранением публичного адреса. Создание дублей не требуется.

## Сохранность данных

SQLite находится в `output/desk/desk.sqlite3`, новые фотографии и пакеты —
в `output/desk/demos/`. Папка `output/` не попадает в Git. Файлы демо старых
запусков также показываются в панели; храните всю папку `output/` вместе.
Для резервной копии сначала остановите приложение, затем скопируйте `output/`.

Импорт обновляет только исходную информацию: ваши локальные статусы, заметки,
тексты и ссылки на демо сохраняются. Запись обратно в Google-таблицу не выполняется.
CSV листа «Магазины» можно импортировать вручную, если доступ через Chrome не работает.

Панель слушает только `127.0.0.1`; менять данные могут запросы из самой панели.
Ключ Delokay не возвращается в API, не записывается в SQLite и логи.

## Отключение Apify

15 октября 2026 workflow «Cloud profile checks» отключён непосредственно в GitHub
(`Disabled`, `This workflow was disabled manually.`). Его расписание больше не
запускает Apify. Workflow «Discover stores» проверен и оставлен включённым:
он продолжает пополнять таблицу. Дополнительно в локальном `cloud.yml` убраны
cron и запуск при push; оставлен только ручной запуск для прежнего инструмента.
Apify API token не удаляется и не используется локальной панелью.

## Проверка изменений

```sh
.venv/bin/python -m unittest tests.test_desk tests.test_personal_demos tests.test_account_languages
.venv/bin/python -m scripts.check_desk
```

Последняя команда проверяет уже запущенную панель через Chrome и временно
меняет одну локальную заметку с обязательным восстановлением.

## Статистика языков и локальный просмотр

В панели показаны две группы: оценки по био/подписям (тёмная часть полосы)
и предварительные оценки по поисковым сниппетам (светлая часть, ≈).
Язык поискового запроса не используется как доказательство языка аккаунта.
Короткие и неоднозначные тексты могут остаться без определения.
Фильтр языка действует вместе с поиском и статусами; список разбит на страницы.
После нового локального сбора статистика уточняется автоматически.

В карточке собранного аккаунта есть «Локальный просмотр»: это проверка
исходных фотографий и описаний до публикации. Адрес 127.0.0.1 клиенту не отправляется.
Публичная ссылка и черновик первого сообщения появляются после успешной публикации.
Обновление Delokay опубликовано 15 октября 2026: действующий сервер поддерживает
все десять языков. Перед публикацией клиент всё равно проверяет список
поддерживаемых сервером языков и останавливается до создания магазина,
если подключён другой сервер со старой версией.
Панель управления и Telegram-бот остаются на своих прежних языках;
расширены язык витрины и черновики первого контакта. Часть второстепенных
стандартных текстов новых языков пока использует английский резервный перевод.
