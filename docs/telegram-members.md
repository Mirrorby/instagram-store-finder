# Участники Telegram-групп → Google Sheets

Откройте `scripts/Telegram-группы.command` двойным щелчком. Введите ссылку
на группу или несколько ссылок через пробел, например:

```text
https://t.me/yardsalemd @another_group
```

Для каждого чата создаётся отдельный лист в существующей таблице из
`config/destination.json`. Название листа совпадает с названием чата,
кроме недопустимых для Sheets символов или слишком длинного названия.
При совпадении названий добавляется ID группы. Существующие листы других
модулей не используются. Лист привязан к Telegram ID группы: новая ссылка
или название той же группы обновляет прежний лист.

## Первый запуск

1. Откройте https://my.telegram.org → API development tools и создайте
   приложение. Нужны `api_id` и `api_hash` — это не токен бота.
2. Запустите ярлык. Он создаст отдельное Python-окружение и установит
   `requirements-telegram.txt`, не затрагивая Instagram-окружение.
3. Введите `api_id`, `api_hash` и путь к JSON-ключу сервисного аккаунта Google,
   который уже имеет доступ редактора к существующей таблице.
   Если ключа на Mac нет, его нужно скачать/создать в Google Cloud;
   существующий GitHub Secret невозможно прочитать обратно.
4. Введите номер телефона в международном формате, код входа Telegram
   и пароль двухэтапной защиты, если он установлен. Вводите их только
   в локальном Терминале. В чате или GitHub сохранять их не нужно.
5. После завершения откройте напечатанную ссылку на новый лист.

Настройки и сессия остаются в `.auth/` (исключена из Git, права файлов 600).
Повторный запуск обычно не требует входа. Сессия даёт доступ к вашему аккаунту:
не передавайте файлы `.session`. При необходимости отзовите сеанс через
Telegram → Настройки → Устройства и удалите `.auth/telegram-members.session*`.

Приватные ссылки поддерживаются только для групп, в которые аккаунт уже
вступил. Скрипт сам не вступает в группы. Приватная пригласительная ссылка
не записывается в общую таблицу.

## Работа с таблицей

- A:L — сведения Telegram; при повторном сборе обновляются.
- M:R — ваши поля: статус, товары, дата первого сообщения, следующий контакт,
  демо и заметки. Для существующих строк скрипт их никогда не записывает.
- Новые участники добавляются в конец со статусом «Новый».
- Дубли исключаются по Telegram ID внутри группы. Один человек в разных
  группах будет в каждом соответствующем листе.
- Впервые найденная дата сохраняется. Время указано по Минску.
- Старые контакты не удаляются, даже если они не вернулись в новой выборке.
  «Последний сбор» показывает последнее наблюдение, а не факт выхода из чата.
- Боты и удалённые аккаунты сохраняются и помечаются, их можно отфильтровать.
- Если username отсутствует, ссылка на профиль остаётся пустой: открытие
  пользователя по одному ID из Google Sheets не гарантируется.
- Не меняйте первые 12 заголовков, Telegram ID и ID группы. Сортировать
  нужно весь диапазон A:R вместе, а не отдельный столбец.

Telegram может скрывать список или возвращать только часть участников.
Скрипт не обходит ограничения. При ошибке чтения этого чата запись не
начинается. Если итератор завершился, но количество меньше заявленного
Telegram, результат сохраняется с явной отметкой неполной выборки.
Количество участников может изменяться прямо во время сбора.
При FloodWait сбор останавливается, время ожидания печатается в Терминал.
Для аналитики учитывайте только реально полученные контакты.

Параллельный запуск на одном Mac блокируется. Не запускайте копии на
нескольких компьютерах и не сортируйте таблицу во время записи.
При сетевой ошибке записи повторите сбор: идентификация по ID предотвращает
дубли. Автоматической отправки сообщений нет.

## Командная строка

```sh
python3 -m venv .auth/telegram-venv
.auth/telegram-venv/bin/python -m pip install -r requirements-telegram.txt
.auth/telegram-venv/bin/python -m store_finder.telegram_members https://t.me/yardsalemd
```

Можно передать несколько групп, `--credentials /путь/к/ключу.json` и
`--spreadsheet ID_таблицы`. Для среды с секретами поддерживаются
`TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `GOOGLE_SERVICE_ACCOUNT_JSON`,
`GOOGLE_SHEET_ID`. По умолчанию используется существующая таблица.

Без UI-запуска установка зависимостей выполняется явно командой выше.
Тесты без подключений и секретов:

```sh
python3 -m unittest tests.test_telegram_members
```
